#  MPU6050 Motion Monitoring with NodeMCU and KiwisIoT

## 📌 About the Project

MPU6050 Motion Monitoring with NodeMCU and KiwisIoT is an IoT-based project designed to detect and monitor movement, acceleration, and orientation in real time.

Using a NodeMCU ESP8266 microcontroller and an MPU6050 sensor, the system collects motion data through its built-in 3-axis accelerometer and 3-axis gyroscope.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can visualize and monitor real-time acceleration, angular velocity, and motion changes through an online dashboard.

This project demonstrates how IoT technology can support motion tracking, activity monitoring, device movement detection, and smart automation applications.
